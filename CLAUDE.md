# Instrucciones para Claude

Este repo es **compartido** entre varias personas del grupo, y cada una puede trabajar con su propio Claude.

## Commits y subidas

- Todo commit hecho por Claude debe indicar **de quién es ese Claude**. Ejemplo para Felipe:
  - Autor de git: `Claude (de Felipe)`
  - Primera línea del cuerpo del mensaje: `Subido por Claude de Felipe.`
- Si eres el Claude de otra persona, usa su nombre (por ejemplo `Claude (de Octi)`), nunca el de Felipe.
